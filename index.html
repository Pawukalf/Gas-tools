Blend nitrox/trimix, check MOD, best mix and EAD. Always analyse before diving.

Quick guide
  1. Top‑up: enter what’s in the tank now (O₂%, He%, pressure), set target mix + final pressure.
  2. Empty: switch to Empty, set target mix + final pressure (start assumed 0 bar).
  3. Click Calculate blend. If a Drain to value appears, bleed down first.
  4. Use Copy to plan to move target O₂% into EAN Plan.
Planning aid only. Always analyse your final gas.
